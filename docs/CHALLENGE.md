# Challenge notes

This is the team's interpretation of the supplied brief, not an organizer-issued
rules document. Check the official brief and amendments before competition.

Fly autonomously from the launch mark through the indoor course to the pad.
Outbound traversal must negotiate the obstacles/openings, not fly over the walls.

The supplied project notes describe:

- A 180-second total run allowance.
- Five checkpoint groups: corridor (4 points), maze exit (7), tunnel (10), chicane
  (7) and destination landing (7).
- A below-wall completed-run component of `35 + 20 * T_fastest / T_finish`, plus
  5 points for the window option.
- A successful return-to-start multiplier of 1.25 on run points. The notes cite
  rule 7.10 as permitting an over-barrier return after destination landing.
- Judged presentation and generality components alongside run performance.
- No separately named package-delivery task.

Nine simulation gate planes subdivide geometry; they are not nine scored groups.

Historical notes permit published maps but prohibit carrying learned maps/run data
between competition runs while allowing code/parameter development. Check trained
appearance/speed models against the current event's data policy before use.

Outbound completion, pad hover, pilot landing, autonomous landing/disarm and return
bonus are distinct outcomes. State which occurred and whether timing uses source
simulation time or lab wall time. Video length and reference duration are not
finish times.
