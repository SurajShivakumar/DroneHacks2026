# GB10 simulator workspace

The GB10 is ARM64 Ubuntu 24.04; use Jazzy/Harmonic rather than the laptop's
Humble/Harmonic pairing. The project lives at `~/dronehacks-2026-gb10`, native
sources/builds at `~/dronehacks-runtime`. This is a separate simulation host,
not a managed companion container or real flight computer.

SSH authentication worked. At initial inspection, sudo required an interactive
password and Docker access was denied. Do not put a password in scripts/chat.
The GB10 GPU already had other compute workloads; leave those untouched.

Administrator installation (run in a GB10 terminal):

```bash
sudo bash ~/dronehacks-2026-gb10/sim/runtime/install_gb10_dependencies.sh
```

Then, as the ordinary user:

```bash
cd ~/dronehacks-2026-gb10
bash sim/runtime/inspect_gb10.sh
```
